# 战斗布局优化 — 方案对比与实施记录

> 日期：2026-05-23

## 1. 现状分析（代码 + 布局审计）

当前垂直堆叠布局（1280x720 预算）：
| 区域 | 高度 | 问题 |
|------|------|------|
| 顶行：玩家HUD(左) + 敌人HUD(右) | 73px | 玩家/敌人分离两侧，战斗关系弱 |
| 意图横幅 | 52px | 居中，OK |
| 中央战斗舞台 | 855px(expand) | **占满剩余空间，大量空白** |
| 资源行 | 62px | 集中居中，未利用左右 |
| 手牌行 | 154px | 底部，OK |
| 日志 | 36px | 全宽，与"弱化"矛盾 |

## 2. 我的优化点总结
1. 中央舞台空间浪费 → 应收窄
2. 拖拽距离远（底部手牌 → 右上敌人）→ 应拉近
3. 玩家/敌人分离 → 应并排居中
4. 日志全宽 → 应贴边收窄
5. 资源行集中 → 应分散利用空间

## 3. 用户方案
- 玩家/敌人放到战斗界面**中间区域**
- 日志放到**中间贴左侧**

## 4. 最优方案（融合）
```
┌──────────────────────────────────────────────┐
│ [玩家HUD]  [意图横幅]  [敌人1][敌人2]         │ ← 顶行：三者并排居中，操作距离最短
│                                              │
│  ┌─日志──┐  ┌───── 战斗舞台 ─────────────┐   │ ← 日志贴左（竖排窄条），舞台收窄
│  │        │  │   玩家 ⚔ 敌人             │   │
│  │        │  │                           │   │
│  └────────┘  └───────────────────────────┘   │
│ [能量球] [抽/弃/耗chip]       [回合N]        │ ← 资源分散
│ [圣杯瓶]      [手牌]          [结束回合]     │ ← 底部不变
└──────────────────────────────────────────────┘
```

**取舍**：
- 采纳用户"玩家/敌人居中"：顶行三者并排（比用户"移到中央舞台"更简洁，避免舞台内再嵌 HUD 的复杂度）
- 采纳用户"日志贴左"：日志移到中区左侧竖排，腾出全宽
- 保留我的"资源分散/舞台收窄"：提升信息密度
- 敌人 HUD 保持在顶行右侧（操作距离已大幅缩短，且多敌人横向排列自然）

## 5. 实施
- CombatHudView 重构：顶行 = 玩家 + 意图 + 敌人 并排；中区 = HBox(日志左 + 舞台右)；资源分散
