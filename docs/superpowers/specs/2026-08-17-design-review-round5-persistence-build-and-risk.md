# 第五轮设计评审：持久成就、构筑共鸣与跨局传承

> 命题：在 B/C 簇落地（追忆、引火、大卢恩、癫火、壶哥、杀商人，6 项全部实现，49 测试全绿）之后，**下一轮该往哪长？**
> 现状：48 卡 / 20 护符 / 19 敌人 / 26 事件 / 6 出身；NG+ ×7 + 誓约 Ⅰ–Ⅴ + 记忆 + 死亡回响外循环完整；难度锚点稳定（一贫如洗 vs 玛尔基特 78.7% / 接肢贵族 56.0%）。I1 死因解析 / I2 血迹 / I3 追忆决斗仍为待选项。

## 结论先行

第四轮解决了"内容记忆点"与"禁忌抉择"。游戏现在能产出值得分享的瞬间——灵庙双拿、献瓶抉择、癫火之王、亚历山大的告别。

但缺三样让它在**长期留存**上从"好玩"变成"离不开"的东西：

1. **跨局传承的厚度。** 魂系的灵魂不在单局机制，在"上一局的努力让这一局不一样"——法环的 NG+ 解锁新敌人、死亡搁浅的异步联机、Hades 的家族树。本作已有胜利解锁 NG+/誓约 + 死亡回响 + 记忆商店，但**缺少一条"你的成就被世界记住"的可视化管道**。赢了 30 次还是 1 次，对新手来说看起来一样。
2. **构筑的"1+1>2"。** 当前构筑是加法：卡 A 的伤害 + 卡 B 的状态 + 护符 C 的百分比。没有**协同效应**——法环的祷告叠加（火焰加持+圣血）、StS 的牌组类型（力量/防御/毒），玩家不会说"我把祷告和武器卡混出连锁了"。
3. **局内风险系统的多样性。** 目前局内"赌一把"的选项只有癫火。一个完整的风险光谱需要**多个层级的风险源**：开局选的（誓约）、局内捡的（癫火）、以及**主动招惹的**（诅咒/灾厄）。

据此提出 **J1–J7 七项创新**，分三簇：持久成就（持久簇）、构筑深度（构筑簇）、风险系统（风险簇）。

**若只做三件事：J1（留存引擎）→ J2（构筑灵魂）→ J3（风险光谱补完）。**

## 二、持久簇：你的成就被世界记住

### J1 褪色者铭牌（Tarnished Legacy）—— P0 · 中 · ★★★★★

**原型**：法环开头"你是被放逐的褪色者"——你的身份由成就定义。StS 的里程碑系统。

**设计**：
- Profile 新增 `legacy: Dictionary`，记录以下里程碑（示例）：
  - **通关计数**：首次 / 5次 / 10次 / 20次 / 50次 / 100次
  - **难度印记**：NG+7 通关、誓约 Ⅴ 通关、癫火之王通关、无瓶+强敌双挑战
  - **收集印记**：全部追忆解锁、壶哥全对话、神授塔全部激活
  - **风格印记**：纯祷告通关（武器卡0张）、纯腐败通关、纯姿态崩解通关（攻击卡0张直接处决）
- **铭牌在标题界面展示**：标题背景不再是静态的，而是根据最高铭牌变化（"放逐者"→"黄金裔"→"艾尔登之王"→"癫火之王"——4 种背景/配色）。
- **铭牌解锁 = 解锁跨局内容**：
  - "黄金裔"（通关5次）→ 出身选择界面解锁**初始遗物自选**（从 3 个随机护符中挑 1 个，不通过记忆商店）。
  - "艾尔登之王"（通关20次）→ 解锁**隐藏出身**（如"半死人"：HP 60 但开局自带 2 张《黑焰》+ 护符「黑焰护符」）。
  - "癫火之王"（癫火通关1次）→ 癫火卡以 3% 概率出现在所有奖励池中（不再需要进教堂）。
- ProfileService 扩参：`record_legacy_milestone("milestone_id")`，每次胜利/死亡后检查并自动记录。

**为什么值得**：留存是 roguelike 的生命线。当前系统里，玩 30 小时和 3 小时看到的界面一样——J1 让"继续玩下去"有**可见的理由**。

**承接点**：`ProfileService` 增 `legacy` 字典 + `record_legacy_milestone()`；`TitleScreenView` 读 legacy 改变背景/称号；`OriginScreenView` 按 legacy 解锁隐藏出身。工作量：中（主要是里程碑定义 + 标题 UI 适配）。

### J2 构筑共鸣（Rune Resonance）—— P0 · 中 · ★★★★★

**原型**：法环的祷告叠加（火焰加持+圣血→火伤翻倍）、StS 的力量/防御/毒构筑标签。

**设计**：
- 每张卡有一个隐藏的 **共鸣标签**（`resonance: String`），如 "physical"/"magic"/"prayer"/"curse"/"blood"/"rot"。
- Profile 新增 `resonance_bonus: Dictionary = {"physical": 0, "magic": 0, ...}`——记录每个标签的**通关计数**。
- 开局时，找到你通关最多的标签（如 prayer = 5 次），在本局**开局赠送一个共鸣护符**：
  - 物理共鸣护符：攻击卡额外造成 +1 姿态
  - 祷告共鸣护符：祷告卡消耗 -1（最低 0）
  - 腐败共鸣护符：开局 +1 腐败状态（对敌人，第 1 回合生效）
- 共鸣护符是**跨局成长的**——你用祷告通关得越多，共鸣护符越强（+1 姿态 → +2 → +3...上限 +5）。
- 共鸣标签在 EndScreen 展示："你以祷告构筑通关（+1 祷告共鸣）"。

**为什么值得**：解决"构筑纯加法"问题。玩家会说"我上局祷告通关了，这局祷告更便宜了——再试试纯祷告"。共鸣系统让"尝试不同构筑"有**可累积的回报**，而不只是"这局好玩就完事"。

**承接点**：CardData 增 `resonance` 字段；ProfileService 增 `resonance_bonus`；开局 `apply_vow_start` 后追加共鸣护符；新增 6 个共鸣护符（hook 复用：combat_extra_ember / combat_strength / stance_percent 等）。工作量：中。

## 三、构筑簇：1+1>2

### J3 祷告连锁（Prayer Chain）—— P0 · 中 · ★★★★★

**原型**：法环同时附魔多个祷告（火焰+黑焰+腐败）→ 伤害叠加；StS 的 Fast/Slow Magic。

**设计**：
- 新增规则：**连续打出 2 张及以上「祷告」或「魔法」卡（同类型）→ 触发连锁**。
  - 2 连：第 2 张卡伤害 ×1.3
  - 3 连：第 3 张卡伤害 ×1.6 + 额外施加 2 易伤
  - 3 连+护符「神皮剥理者」：连锁不消耗额外集中（当前连锁额外消耗 1 集中，防无脑连打）
- 连锁状态在 CombatHudView 显示："🔥 祷告连锁 ×2"
- 连锁在第 1 回合结束或打出非同类卡时中断
- 平衡：连锁卡额外消耗 1 集中（总上限受 max_ember 限制）；打断机制保证"全祷告牌组"不是最优解

**为什么值得**：祷告/魔法卡目前是"打了就完事"——J3 让它们有了**节奏感**。玩家需要决定"这一张要不要连"，而不是"能放就放"。这也给了纯祷告构筑（J2 共鸣的下游）真正的操作深度。

**承接点**：CombatController 增 `chain_count: int` / `chain_type: String`；`play_card` 时检测同类型 → 乘数 + 消耗。CombatHudView 增连锁指示器。工作量：中。

### J4 武器技艺（Weapon Art）—— P1 · 小中 · ★★★★

**原型**：法环的武器特殊攻击（战灰附魔 + 特殊招式）；StS 的武器卡。

**设计**：
- 当前武器升级（M1 武器等级）只提升伤害倍率。J4 在**武器达到特定等级时解锁专属技艺卡**：
  - 长剑 Lv3 → 解锁《长剑突刺》（cost 1，伤害 10，姿态 5，仅持有长剑时可用）
  - 弯刀 Lv3 → 解锁《旋风斩》（cost 2，对全体敌人伤害 8，姿态 2×）
  - 大圆盾 Lv3 → 解锁《盾冲》（cost 1，获得 15 护甲 + 下回合攻击 +5）
- 技艺卡**不占牌组空间**：它们存在于一个独立的"技艺槽"（每局 1 个槽位），每回合可以选择"使用技艺"代替出 1 张手牌。
- 锻造石消耗：升级需锻造石（已有smithing系统），LV3 = 3级（最高级）→ 解锁技艺是整局锻造的目标终点。

**为什么值得**：锻造系统目前"升级 → 伤害×1.1"是纯数值——J4 让锻造有了**内容解锁**的味道（"我这把剑升到满级会出什么技艺？"）。技艺槽也给了"武器选择"真正的玩法意义。

**承接点**：RunState 增 `weapon_art_slot: String`；CombatController 增技艺出招逻辑（独立于手牌）；WeaponService 增技艺解锁表；`GraceService` 锻造选项显示"下一级解锁：XXX技艺"。工作量：小中。

## 四、风险簇：更完整的光谱

### J5 腐败灾厄（Scarlet Aeonia）—— P1 · 中 · ★★★★

**原型**：法环的腐败之龙——局内随机事件，中招则持续掉血，但奖励丰厚。

**设计**：
- 地图新增第五种节点类型"**灾厄**"（低概率出现，每局 0–2 次）：进入后强制施加局内**腐败诅咒**（每回合 −3 HP）；但获得大量卢恩（+100）+ 一张强卡（《腐败龙息》全体 15 + 腐败 3）。
- 诅咒可以在**特定 Grace 选项**（消耗 1 圣杯瓶上限）或**特定事件**中解除——不解除则持续扣血直到死亡。
- 灾厄节点在地图上有**独特图标**（红色龙息），玩家可主动回避——但回避 = 放弃奖励。

**为什么值得**：填补"主动招惹"这一风险类型。誓约是开局选的，癫火是局内捡的，灾厄是**地图层主动赌**的——三者构成完整的风险光谱。

**承接点**：MapGenerator 增 `calamity` 节点类型；新增灾厄事件 tres；CombatController 增每回合扣血逻辑；GraceService 新增解除诅咒选项。工作量：中。

### J6 半死状态（Hollowing）—— P1 · 小 · ★★★★

**原型**：黑暗之魂的半死——死后最大生命永久降低，需用"人性"恢复。

**设计**：
- Profile 新增 `hollow_level: int = 0`。每次死亡 → hollow_level +1（上限 5）。
- hollow_level > 0 时：开局最大生命 −10% / 级（5 级 = −50%）；但伤害 +5% / 级（半死者的疯狂）。
- 胜利 → hollow_level 减 1（"你的身体重新凝聚"）。
- 开局 Grace 可用 100 卢恩购买"人性"（hollow_level −1，每局限 1 次）。
- 半死状态在 RunHeaderView 显示："半死 ×3（HP −30% / 伤害 +15%）"

**为什么值得**：魂系玩家最熟悉的"死亡有代价"系统。与死亡回响不同（回响跨局可夺回卢恩），半死是**不可逆的跨局惩罚**——除非你赢。这给 NG+ 后期的重复死亡增加了真正的紧张感。

**承接点**：ProfileService 增 `hollow_level`；`record_death` → hollow_level +1；`record_victory` → hollow_level −1；开局 `apply_vow_start` 追加半死修饰（HP −10%/级，伤害 +5%/级，走 `combat_strength` hook）。工作量：小。

### J7 前世的遗物（Echo Artifact）—— P2 · 小 · ★★★☆

**原型**：死亡搁浅的异步联机——别人的建设帮到你；法环的骨灰召唤。

**设计**：
- 每次死亡在 Profile 留下**回响遗物**（`echo: {artifact_id, strength}`），基于你死前的最强构筑方向（物理/魔法/祷告/腐败）。
- 下一局开局，如果上次不是在本层死亡（即你进步了），可以在第 1 个 Grace 处**继承 1 个前世遗物**：
  - 物理遗物 → 护符「前世战士之盾」（战斗开始 +5 护甲，持续 3 回合）
  - 魔法遗物 → 卡《前世魔光》（cost 1，伤害 8，每局限用 2 次）
  - 祷告遗物 → 开局 +1 集中
  - 腐败遗物 → 对第 1 个敌人施加 3 腐败
- 遗物在第 5 层结束时消失（"前世的痕迹淡去"）。

**为什么值得**：给"死亡 → 学习 → 进步"一个**游戏内的正向反馈**。你输了，但你的下一局起点比上次高一点——即使没有夺回响，世界也在记住你。

**承接点**：ProfileService 增 `echo_artifact`；`record_death` 时根据 run 的构筑标签记录遗物；GraceService 第 1 次 Grace 新增继承选项。工作量：小。

## 五、不做的事（克制清单）

1. **不做真正的多人联机。** 异步系统（血迹/回响）已经提供了"与过去对话"的体验；同步联机是引擎级改动，暂缓。
2. **不做卡牌合成/熔炼。** StS 的牌组管理已经靠移除/替换够用，加合成会增加 UI 复杂度且收益递减。
3. **不做第四幕。** 12 层的节奏已经验证过，加长 = 拖沓而非丰富。如果需要更多内容，靠 NG+/誓约/挑战/共鸣的纵向深度解决。
4. **不做随机事件生成器。** 手工编写事件（如壶哥线）质量远高于程序生成。事件数量 26 → 30 是合理的上限。
5. **不做强迫性的每日任务/赛季。** 这是单机 Roguelike，不是 F2P。

## 六、优先级与实施顺序

| 优先级 | 项 | 工作量 | 一句话 |
|---|---|---|---|
| P0 | **J1 褪色者铭牌** | 中 | 留存引擎——让"继续玩"有可见理由 |
| P0 | **J2 构筑共鸣** | 中 | 构筑灵魂——跨局成长让每次尝试都有累积回报 |
| P0 | **J3 祷告连锁** | 中 | 操作深度——祷告/魔法从"打了就完"变成"连打有节奏" |
| P1 | J4 武器技艺 | 小中 | 锻造目标感——满级武器解锁专属招式 |
| P1 | J5 腐败灾厄 | 中 | 风险光谱补完——地图层主动赌 |
| P1 | J6 半死状态 | 小 | 死亡代价——魂系最经典的跨局惩罚 |
| P2 | J7 前世的遗物 | 小 | 异步正向反馈——输了也让世界记住你 |

**若只做三件事：J1 → J2 → J3。** 分别回答"我凭什么继续玩""我的构筑有成长感吗""这局的操作有深度吗"——留存、构筑、操作，正好补齐当前缺的三个维度。
