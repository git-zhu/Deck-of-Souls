## 2. 本次重构范围（3 项 P0/P1，展示层）

### 重构 A：卡牌悬停放大（StS 标志交互）— P0
- 手牌悬停时：放大到 1.5x + 上浮（offset_y 负值）+ z_index 提升，模拟"拿起牌"
- 悬停离开恢复；拖动时跟随鼠标（DragCard 已有 preview，改为跟随全卡）
- 实现：在 card_button 上挂 hover 逻辑（mouse_entered/exited + tween），放大时 z_index 提升并在手牌行内保持原位

### 重构 B：状态 buff/debuff 图标化 + 回合数 — P0
- 用已下载的 Kenney 图标（sword/shield/skull/fire/diamond）+ 语义色，替换纯文字 chip
- 每个状态 chip：图标 + 数值（+ 剩余回合，若系统支持）
- 敌人同样适用（stance/rot/bleed 等）
- 实现：status_chip 增加 icon 参数；compact_fighter_hud 传入图标映射

### 重构 C：能量（集中）+ 回合数显示强化 — P1
- 能量从"集中 3/3"小 chip 升级为**大号能量球/数字**（StS 左下角能量球风格）
- 顶部新增"回合 N"标签（combat.turn_count，若 CombatController 有该字段则读取，否则展示层计数）
- 实现：resource_chip 或独立 energy display 组件
