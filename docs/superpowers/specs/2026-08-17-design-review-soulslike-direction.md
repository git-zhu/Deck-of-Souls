# 设计审视：从"换皮尖塔"到"有魂的卡组构筑"

> 日期：2026-08-17
> 视角：以顶级系统设计师立场，对照《艾尔登法环》（体验内核）×《杀戮尖塔》（玩法骨架）的融合目标，审视当前设计。
> 依据：全量阅读 `scripts/core/*`、`data/**`、既有设计文档与 Monte Carlo 平衡报告（非印象流评审）。
> 目标函数：**魂类特点 + 肉鸽卡牌玩法的独创性 × 趣味性 × 可玩性 × 可重复游玩价值**。

---

## 0. 一句话结论

**骨架（StS 循环）与皮肤（法环设定）都已 100% 就位，但"魂"还没有装进去。**

当前产品是一个合格的 StS 克隆 + 法环皮肤包：能量/手牌/意图/三选一都是 StS 的，名字/地名/卢恩/圣杯瓶是法环的。但法环真正让玩家难忘的体验内核——**可学习的强敌、姿态崩解的处决时刻、死亡与卢恩的重量、构筑的自由**——在机制层几乎都只停留在"数值贴皮"：

| 法环体验内核 | 当前机制实现 | 差距定性 |
|---|---|---|
| 姿态崩解 → 处决/防反 | 姿态条归零 = 被动 +35% 伤害窗口 | **无玩家决策，纯数值修饰器** |
| 强敌可学习、可背板 | 敌人招式均匀随机（`rng.randi_range`） | **无法学习、无法精通、无成长感** |
| 死亡失去卢恩、可夺回 | 死亡 = run 直接结束，卢恩清零 | **死亡无重量，魂味归零** |
| 构筑自由（力敏智信） | 属性只进伤害公式；奖励池按幕、不按流派 | **有"派系"无"协同"** |
| 碎片化叙事、道德模糊 | 事件多为纯数值交换（20 卢恩 → 15% 治疗） | **事件无风险、无性格** |
| NG+ / 多周目 | 无任何跨局内容（grep 确认无 unlock/ng+/profile） | **重玩价值只有内循环** |

好消息：**最有价值的零件已经在代码里**（姿态条、卢恩、圣杯瓶、五属性、锻造石、多敌人群怪）。问题不是缺系统，而是这些系统被当作"数字"使用，而没有被当作"决策点"使用。顶级设计与普通设计的差距就在这里：**每一个系统要么制造决策，要么制造情绪，否则只是 UI。**

---

## 1. 现状盘点（证据基线）

- 12 层（3 幕 × 4），每层从加权随机的 3 个选项中盲选；4/8/12 层固定幕 Boss。
- 战斗：3 集中/回合，抽 5（+记忆石/护符），护甲每回合清零（StS 式），意图可见。
- 内容量：28 卡 / 18 敌 / 8 护符（全为平坦数值）/ 15 事件 / 6 出身 / 8 赐福选项 / 11 武器。
- 敌人意图只有 6 种（attack / attack_block / buff / debuff / rot / attack_rot），**均匀随机选取，无权重、无序列、无阶段**。
- 每幕奖励卡池仅 6–8 张，且跨幕重叠（`great_knife`、`black_flame`、`rotten_breath` 重复入池）→ 实际可选卡面更窄。
- Monte Carlo 报告：**普通/精英战对裸卡组 100% 胜率（偏易）**；预言家 Boss 胜率已从 21% 修至 76%。
- 无卡牌升级、无地图分层、无任何跨局进度（代码库中不存在相关字段）。

## 2. 核心诊断：五个结构性问题

### D1【P0】没有外循环：重玩价值只靠单局内循环支撑

StS 的重玩性 = 升阶 1–20 × 角色 × 构筑方差；法环的重玩性 = NG+ × 构筑自由。本作目前两者皆无：

- 玩家首次通关后，第二局的**决策空间与第一局完全相同**（地图虽随机，选项语义不变）。
- 无解锁、无升阶、无图鉴、无出身专属目标、无成就文本。
- 单局仅 12 层（约 8–10 场战斗，20–30 分钟），这个长度**必须**靠外循环给重复游玩一个理由，否则重复 = 重复。

**机会**：NG+ 与多周目强化是法环原生概念，实现成本极低（敌人乘数 + 掉落乘数 + 解锁门槛），是对重玩价值性价比最高的一刀。

### D2【P0】姿态系统是全游戏最被浪费的资产

姿态崩解（poise break）是魂系最具辨识度的交互：打空姿态条 → 处决/防反的**高光时刻**。当前实现：

- 姿态归零 = 易伤 +1、伤害 ×1.35，随后姿态条自动回满。玩家**没有任何主动选择**。
- "姿态伤害"只是卡牌上的附属数字，游戏里不存在一张"为了破姿态而存在"的卡，也不存在"攒着重击等破防"的决策链。
- 盾系卡（heater_shield / buckler）已有"敌人攻击时触发"的钩子雏形——这正是防反的种子，但没有长成系统。

**机会**：把姿态崩解改造成**二选一决策时刻**：
- 「处决」：一次性大额伤害（法环式处决）；
- 「防反」：获得护甲 + 返还集中（延续进攻节奏）。

这一个改动就能让每场战斗产生 1–3 个"心跳时刻"，是本项目区别于 StS 的**最大差异化杠杆**。

### D3【P0】敌人是"数值袋"，不是"老师"

魂类的难度从来不是数值高，而是**可学习的、具体的威胁**：背板 → 尝试 → 精通 → 成就感。当前：

- 所有敌人招式均匀随机。玛尔基特的 22 伤黄金锤与"野心之火"易伤出现概率相同——玩家无法预判、无法背板、胜利归因于抽牌而非学习。
- Boss 无阶段转换（`is_boss` 仅是标签）。法环 Boss 的"二阶段"是标志性体验。
- 意图类型仅 6 种。`player_bleed` 在 RunState 中有完整的爆发实现，但**没有任何敌人能施加**（死轴，见附录 3）。
- 普通战 100% 胜率不是数值太低的唯一解法——更魂的解法是让敌人**有个性**：野狼成群扑咬（多段小攻）、大树守卫举盾蓄力（可被姿态打断的重击）、法师蓄力一回合的大魔法（telegraph）。

**机会**：MoveData 增加 `weight` / `phase` / 序列字段，数据驱动即可实现"可背板的敌人"，代码改动集中在 `_choose_one_intent`。

### D4【P1】构筑"有派系、无协同"

五属性 + 出身差异化初始卡组已经立起了"力/敏/智/信"四条路的**意图**，但协同网络不存在：

1. **卡牌获取不按流派过滤**。观星者（智力系）的奖励三选一会刷出武器卡。StS 用颜色解决这个问题；本项目可以用"最高属性/出身倾向"加权解决，成本更低。
2. **8 个护符全是平坦数值**（+抽牌/+护甲/+卢恩）。StS 的遗物是构筑方差的引擎，因为它们**改变规则**（"每打 3 张攻击牌抽 1 张"）。当前护符没有一个能改变玩法。
3. **没有流派支撑卡**（archetype enabler）："你每施加 5 点出血立即触发一次"（血派）、"法术卡打出后抽 1 张"（智派）、"姿态伤害 +50%"（重武器派）。没有这类卡，流派就只是伤害公式里的系数。
4. **武器系统有壳无魂**：武器是全局被动加成，无切换/双持/战技绑定决策；锻造石升级 0–10 级对 12 层单局而言太深且纯概率掉落（可能整局 0 石）。
5. 数值不一致（详见附录 1/2/3）：`flame_grant_me_strength` 文本"本回合"实际整场生效；"集中属性 +能量"承诺未实现。

### D5【P1】地图与经济的决策密度不足

- 每层 3 选项**盲选**，看不到任何前瞻信息 → 不存在 StS 式的"路线规划"（为商人绕路、为赐福冒险）。当前体验更接近掷骰，而非探索。
- 事件多为纯数值交换，缺少魂味：**风险赌博**（押上最大生命赌一张稀有卡）、**诅咒交易**（获得强力卡但失去一个瓶位）、**道德模糊**。15 个事件里只有 3 条链，远远不够。
- **圣杯瓶定位暧昧**：免费动作 + 固定 18 点治疗。法环里喝瓶是"有风险的行为"（会被惩罚），这里没有任何代价；且固定值不随生命属性缩放，后期边际价值递减。
- 卢恩只是货币，没有"携带重量"的紧张感。

**机会**：把法环的**地图碎片**机制直接搬进来——每幕开局地图被雾覆盖，花卢恩购买"地图碎片"可预览未来 1–2 层。这是 IP 契合度 100%、代码量极小、却能把盲选变成规划的一手。

## 3. 方向定义：三大支柱

为避免后续开发变成"功能堆叠"，先定义游戏的三根支柱。之后每个 feature 必须能回答"我在强化哪根支柱"：

| 支柱 | 一句话 | 对应体验 |
|---|---|---|
| **Ⅰ 对手感** | 每场战斗都是一堂课：玩家靠学习取胜，而非靠数值碾压 | 可背板的敌人、姿态决策、Boss 阶段、处决时刻 |
| **Ⅱ 死亡的重量** | 每种资源都有代价，死亡会留下痕迹 | 卢恩风险、死亡回响、瓶的代价、诅咒交易 |
| **Ⅲ 构筑的自由** | 力敏智信四条路各有终点，护符改变规则 | 流派卡池、规则护符、卡牌升级、武器抉择 |

当前代码对三支柱的支撑度：Ⅰ ≈ 20%、Ⅱ ≈ 10%、Ⅲ ≈ 35%。**优先级即按此排序。**

## 4. 优化清单（按优先级）

### 第一梯队：立魂（P0，建议立即排期）

**S1. 姿态崩解决策点 —— 项目的差异化核心**
- 姿态归零时进入「破绽」状态，玩家下次命中时二选一：
  - 「处决」：该次伤害 ×2.2，消耗破绽；
  - 「防反」：获得等同于本次伤害 50% 的护甲 + 返还 1 集中，消耗破绽。
- 新增 2–3 张交互卡：「格挡反击」（敌人本回合意图为攻击时打出：完全格挡 + 削减姿态 6）、「重击蓄力」（本回合不动，下回合姿态伤害 ×2）。
- **为什么法环**：处决/防反是魂系战斗的语言；**重玩价值**：每场战斗产生高光时刻，处决流/防反流成为构筑分支。
- 成本：中（CombatController + 2–3 张卡 + UI 选择浮层）。

**S2. 敌人行为模式 —— 把"随机袋"变成"老师"**
- `MoveData` 增加 `weight: int = 1`；`EnemyData` 增加 `phase2_hp_percent` 与 `phase2_moves`（Boss 半血换招式池 + 一次性台词）。
- 给 6 个标志性敌人写"个性"：大树守卫（蓄力重击可被姿态打断）、玛尔基特（二阶段连段）、野狼群（多段小攻压制护甲）、法师（蓄力 1 回合的大魔法）。
- 为凯丹佣兵/守墓斗士补上 `bleed` 意图类型，激活 `player_bleed` 死轴（法环的出血本来就是玩家也要怕的东西）。
- **为什么法环**：背板与精通是魂类的灵魂；**趣味性**：同一敌人在 NG+ 换招式池 = 免费的新鲜感。
- 成本：低–中（数据驱动，逻辑集中在 `_choose_one_intent`，现有测试可覆盖）。

**S3. NG+ 与"誓约"升阶 —— 重玩价值的第一根柱子**
- 通关解锁 NG+：敌人 HP +25%、伤害 +15%、卢恩掉落 +30%、精英必掉锻造石；NG+2/NG+3 递增。
- "誓约"（= StS 升阶，但用魂的包装）：10 级可选修饰器——「破损的瓶」（初始 −1 瓶）、「无恩之地」（赐福不提供治疗）、「鲜血契约」（敌人出血免疫，但玩家出血伤害 +50%）……
- **为什么法环**：NG+ 是法环原生词，誓约对应法环的 covenant 传统；**重玩价值**：直接提供 10+ 小时的重复理由，成本几乎只是数据字段。
- 成本：低。

### 第二梯队：深化构筑（P1）

**S4. 流派化奖励**：战后三选一按"出身倾向 + 当前最高属性"加权过滤；保留 1/3 概率出现"异端卡"（鼓励转型的意外之喜）。

**S5. 规则型护符 ×6–8**（示例）：
- 「血君主之乐」：出血 5 层即触发（原 10）。
- 「辉石杖」：法术卡打出后抽 1 张。
- 「双手剑徽章」：姿态伤害 +50%，但每回合护甲 −2。
- 「黄金树的馈赠」：拾取卢恩时 10% 概率翻倍。
- 「碎星将军的义肢」：处决伤害额外 +50%。
- 「玛莉卡的烙印」：能量上限 +1，但每回合积累 2 腐败。

**S6. 卡牌升级（赐福"锻造刻印"）**：赐福新增选项，花锻造石 + 卢恩将一张卡升级为「+」版本（数值 +30% 或附带效果）。一石三鸟：① 补上 StS 对照表里唯一的 P2 机制缺口；② 给锻造石一个高频消耗口（解决 12 层单局里武器 0–10 级太深的问题）；③ 赐福从"回血点"变成真正的 build 节点。武器升级保留为长线大投资（+10 解锁武器特效卡）。

**S7. 数值修正三连**（见附录，均为小改动）：力量"本回合"语义、集中属性的能量承诺、圣杯瓶改为 25% 最大生命治疗（魂式缩放，且让 vigor 加点与瓶联动）。

### 第三梯队：拓宽世界（P2）

**S8. 地图碎片**：每幕开局未来层被雾覆盖；花卢恩买碎片可预览 1–2 层。把盲选变成规划，IP 契合度满分。

**S9. 死亡回响（外循环货币）**：
- 失败时，本局卢恩的一半凝结为「回响」，记录死亡层数。
- 下一局到达该层时出现「上一局的痕迹」事件：一次性夺回回响（魂味拉满），或献给赐福换取少量永久货币「记忆」。
- 「记忆」用于解锁：新出身皮肤文本、起始携带卡选项、图鉴词条（碎片化叙事，法环本色）。
- 这是"肉鸽的死亡"与"魂的跑尸"之间最优雅的缝合点。

**S10. 事件强化**：新增 5 个风险赌博型事件（押最大生命抽稀有卡；诅咒交易：获得「命定之死」但瓶位 −1；道德两难带隐藏后续链）。

**S11. 普通战节奏压缩**：普通战引入"遭遇机制"——若首回合打出 ≥3 张攻击卡，敌人首轮姿态 −50%（先手压制），把垃圾时间压缩到 2–3 回合，把预算集中给精英/Boss。

**S12. 誓言挑战**：通关后可自选 handicaps（无瓶挑战 / 5 卡组），结算屏记录"誓约达成"文本。社区传播向的免费重玩价值。

## 5. 平衡红线（护栏）

1. **普通战 100% 胜率**：优先用 S11 的节奏压缩 + S2 的敌人个性解决，而不是单纯堆 HP（堆 HP 是无聊的解法）。Monte Carlo 工具作为每次调参的门禁。
2. **易伤无上限**：黑焰 3 层 + 姿态崩解 1 层可滚雪球，建议易伤回合数 cap = 3。
3. **出血爆发 = 16% 最大 HP**：对 Boss 很强，这是打刀流的设计意图，保留；但 S2 引入阶段转换后需复测。
4. **保持 12 层单局长度**：不要扩到 16 层。单局短是肉鸽的优点，预算应投入决策密度而非流程长度。
5. **锻造石保底**：精英战必掉、幕 Boss 必掉高阶石（当前纯概率 35/50/70%，可能整局 0 石）。
6. 每新增系统必须配 headless 测试（本项目的测试基建是同类项目里罕见的资产，务必保持）。

## 6. 路线图

| 阶段 | 内容 | 交付标准 | 支柱 |
|---|---|---|---|
| **A 立魂**（~2 周） | S1 姿态决策 + S2 敌人模式 + S3 NG+/誓约 | 破防选择浮层可用；6 敌有个性招式；通关后可开 NG+；Monte Carlo 全出身胜率 30–80% 区间 | Ⅰ |
| **B 深化构筑**（~2–3 周） | S4 流派奖励 + S5 规则护符 + S6 卡牌升级 + S7 数值修正 | 4 流派各有 keystone 卡与规则护符；赐福"锻造刻印"可升级任意卡；全量测试绿 | Ⅲ |
| **C 拓宽世界**（持续） | S8 地图碎片 + S9 死亡回响 + S10 事件 + S12 誓言 | 外循环货币闭环；图鉴/解锁可存档 | Ⅱ |

每阶段独立可玩、可测、可提交（沿用既有 phase 文档 + headless 测试 + commit/push 工作流）。

## 结语

这个项目已经做对了两件最难的事：**完整的 StS 循环**和**成体系的法环内容映射**（出身/幕/敌人/事件全部原教旨对应原作）。现在欠缺的不是更多内容，而是**把已有系统从数值升级为决策**：姿态要能选、敌人要能学、死亡要留痕、构筑要有规则变量、通关之后要有下一周目。

按三支柱排序执行，6–8 周后，这款游戏将不再是"像杀戮尖塔的法环同人"，而是**只有它能成为的那个东西**：一个用卡牌打的、可以背板的、死了还要回来捡卢恩的魂类游戏。
