# 第三轮设计评审：修正落地后的结构审视（魂系视角）

> 日期：2026-08-17
> 视角：同前两轮——以世界前 1% 的游戏设计师标准，审视《Deck of Souls》。
> 依据：第二轮修正（N1–N12）落地后的代码与数据全量复读（`scripts/core/*`、`scripts/ui/*`、`data/**`），47 项 headless 测试全绿复测，150 次 Monte Carlo 平衡采样。不凭记忆、不凭立场。
> 前情：第一轮（D1–D5 → S1–S12）立骨架；第二轮（N1–N12）补接缝。本轮回答：**骨架与接缝都对了之后，这游戏离"值得再来一局"还差什么？**

---

## 结论先行

第二轮修正全部真实落地且被测试锁定（见下节逐条验证）。三支柱健康度继续上行：**Ⅰ 趣味性 8 / Ⅱ 可玩性 7.5 / Ⅲ 可重复游玩价值 7.5**。

但复读暴露了一类新问题：**前两轮修的是"设计规则"，这一轮发现的是"状态与数值的管道"。** 最严重的一处（M1）是一个真正的存档完整性缺陷——武器等级既不持久、又跨局泄漏。其余问题集中在三个方向：**成长管道的断裂**（武器强化对一半卡牌无效）、**难度曲线的倒挂**（最终 Boss 比第一幕 Boss 弱）、以及**描述与实现不符**（属性说明、护符数值硬编码）。

一句话：**规则已经魂味十足，管道还没接严。**

## 二、本轮新发现：M1–M12

### 🔴 P0 — 正确性 / 存档完整性

#### M1 武器等级状态泄漏：既跨局串档，又存档丢失（真实缺陷）

**现象**：`RunRewardFlow._on_weapon_upgrade_pressed` 升级武器时直接改共享资源：

```gdscript
var weapon = registry.get_weapon(weapon_id)   # 预加载的共享 Resource 实例
weapon.level += 1
```

而 `DataRegistry._load_weapons` 存的是 `DataRegistryPaths.WEAPON_RESOURCES` 里 `preload` 出来的**同一个实例**（不 `duplicate`）。于是：

- **串档**：同一进程里打完一局升过武器，再开新局，`reset_for_origin` 只重置了 `run.weapons`（id 列表），**武器等级原样带进下一局**。玩家凭空白嫖 +N 武器。
- **丢档**：`RunSaveService` 持久化了 `weapons`（id）、`smithing_stones`、`attrs`，**唯独没有武器等级**。退出后"继续"，锻造石和卢恩已经扣了，武器却回到 +0。

**为什么是 P0**：这不是平衡问题，是玩家资产的正确性问题。锻造石掉落（35% 普通战 / 精英必掉 / Boss 必掉）与整条升级经济都建立在这个数值上，而它现在两头错。

**已实证**（一次性脚本复现）：局 A 把打刀升到 +1；同一进程开新局 B，未做任何升级，打刀等级已是 1、武器倍率 1.10（泄漏成立）。存档字段清单中只有 `weapons`（id 数组），没有任何等级字段（丢档成立）。

**修法**：把武器等级搬进 `RunState`（如 `weapon_levels: Dictionary`），`reset_for_origin` 清零、`RunSaveService` 读写、`WeaponService` 从 run 读等级而非从资源读。资源 `WeaponData.level` 只当初始值。

### 🟠 P1 — 成长管道断裂

#### M2 钩子卡不吃武器强化与属性补正（一半卡牌被成长系统抛下）

**现象**：走 `_catalog_steps` 的卡经 `calculate_card_damage`，吃到 **属性补正 + 武器攻击加成 + 武器等级倍率**；但走 `_run_hook` 的卡（初始卡组的主力：`longsword`/`uchigatana`/`club`/`battle_axe`/`lions_claw`/`destined_death`…）伤害是裸的 `N + player_strength`：

```gdscript
"lions_claw":
    var broke := combat.deal_enemy_damage(14 + combat.run.player_strength, 5)
```

**后果**：
- 你在赐福铁砧上敲武器到 +5，`longsword`/`uchigatana` 这些初始卡**一点不涨**——成长感最大的那一刻，恰恰漏掉了陪伴你最久的卡。
- 更刺眼：`lions_claw` 现在进了史东薇尔奖励池（第二幕）。玩家在第二幕捡到一张**永远不随武器成长**的攻击卡，而旁边的 `storm_blade` 走 steps 吃满加成。同一个奖励界面里两张卡的成长曲线不一样，没人能看懂为什么。

**修法**：钩子卡的伤害统一过一层 `calculate_card_damage`（或至少乘 `weapon_multiplier` + 加 `total_attack_bonus`）。初始卡不该是成长的弃儿。

#### M3 最终 Boss 比第一幕 Boss 弱（难度曲线倒挂）

**Monte Carlo 数据（一贫如洗，150 次）**：

| 敌人 | 胜率 | 平均回合 | 剩余HP |
|---|---|---|---|
| 恶兆妖鬼玛尔基特（第4层·幕Boss） | **79.3%** | 18.0 | **29.9%** |
| 接肢贵族（第12层·最终Boss） | 88.7% | 30.6 | 51.0% |

最终 Boss 反而**更好打、打完剩的血更多**。原因是接肢贵族第一阶段的招式池偏"软"：`rot 6`、`debuff 易伤`、`attack_block`——大量回合不造成直伤，给了对手喘息与回复窗口；而玛尔基特起手就是 `attack13×2`、`attack22` 的高压。

**为什么是 P1**：12 层的情绪曲线应当**单调推向第 12 层**。现在第 4 层是峰值，第 12 层是回落——玩家带着"后面会更狠"的预期走到终点，却迎来一个更温的 Boss。这是结构性失望，比单个数值失衡伤害更大。

**修法**（择一或组合）：① 给接肢贵族第一阶段加一招稳定的直伤（把 `rot 6` 换成 `attack_rot`，腐+伤一体）；② 把它的二阶段触发线从 50% 提到 65%，更早进入狂乱；③ 提升 `接肢剑舞` 权重。目标是让它的 MC 胜率压到玛尔基特之下。

### 🟡 P2 — 规则与叙事接缝

#### M4 蓄力打断后，重选意图可能立刻又选中蓄力（打断被自己撤销）

N1 的打断逻辑清空 `_charge` 后调用 `_choose_one_intent(e)` 重选意图——但重选不排除 `charge` 招式。对带蓄力招的敌人（大树守卫、学院法师），完全可能打出：

> 大树守卫姿态崩解，蓄力被打断了！
> 大树守卫压低重心蓄力，下一击不会轻。

打断的叙事在下一行日志里被当场收回。**修法**：因打断触发的重选，临时把 `charge` 类招式从权重池里剔除一次。

#### M5 治疗型祷告被计入"先手压制"的攻击卡数

`play_card` 里先手计数按类型白名单：

```gdscript
if turn == 1 and str(card.type) in ["武器", "战灰", "魔法", "祷告", "传说", "壶"]:
    first_turn_attacks += 1
```

`heal`/`urgent_heal` 是**祷告**，打出它们也算"攻击"。第一回合连打 3 张治疗也能触发"敌人的姿态被打乱了"——主题上站不住。**修法**：改为"该卡结算时实际造成了伤害"才计数（resolver 返回是否产生过伤害），或至少把纯治疗钩子排除。

#### M6 属性面板描述与真实公式不符（玩家按错误信息加点）

`LevelingService.ATTR_INFO`：

| 属性 | 面板说 | 实际代码 |
|---|---|---|
| 灵巧 | "姿态伤害 +1" | 姿态 `+0.5/点`，且**物理卡伤害 +0.5/点**（`_attr_bonus_for_card`） |
| 集中 | "魔法伤害 +1" | 魔法伤害 +1，且**每 3 点 +1 能量上限** |
| 信仰 | "祷告伤害/治疗 +1" | 祷告伤害 +1，但**治疗完全不吃信仰**（`heal_player` 是固定值） |

玩家在赐福花卢恩加点，依据就是这几行字。描述错了，加点决策就建立在错误信息上。**修法**：文案对齐真实系数；信仰的治疗要么接上补正，要么明说"治疗为固定值"。

#### M7 护符数值硬编码在逻辑里，`relic.value` 形同虚设

| 护符 | 数据 value | 代码实际用的 |
|---|---|---|
| 黄金树的馈赠 | `souls_double_chance` value=10 | `rng.randf() < 0.10`（写死） |
| 碎星将军的义肢 | `exec_bonus` value=50 | `ceil(exec_bonus * 1.5)`（写死） |
| 双手剑徽章 | `stance_up_block_down` value=50 | `* 1.5`、护甲 `−2`（写死） |
| 玛莉卡的烙印 | `ember_and_rot` value=1 | 能量 +1 走数据，腐败 +2 写死 |

改 `.tres` 数值不产生任何效果——这是个维护陷阱，也让"护符数值"成了假的。**修法**：逻辑改读 `relic.value`（翻倍概率 = value/100、处决加成 = value%、姿态加成 = value%、腐败 = value）。

#### M8 出身屏誓约描述未说明"累积生效"，Ⅴ 容易被误读

`VOW_DESCRIPTIONS` 每级只写**本级增量**（"誓约Ⅴ 死荫：最大生命 −20%"），但实现是累积的（立 Ⅴ 同时吃 Ⅰ–Ⅳ 全部代价）。新玩家会以为"Ⅴ 只扣 20% 血"，实际是 瓶−1 + 治疗减半 + 敌伤+10% + 抽牌−1 + 血−20%。**修法**：描述改为"在以上所有誓约之上，再…"，或在 Ⅳ/Ⅴ 条目里显式列出累积总账。

#### M9 记忆祝福链用"消耗前"的记忆值判定 relic 祝福

`_start_run` 读一次 `mem`，选携带卡花掉 50 后，`_maybe_relic_blessing(mem)` 收到的仍是旧值。于是 120 记忆的玩家：花 50 选卡（余 70）→ 仍因旧值 120≥100 拿到起始护符。若设计本意是"祝福时刻记忆≥100"，应在选卡后重读；若是"开局快照≥100 送双祝福"，就该写进文档，否则这是隐性福利。**修法**：`_maybe_relic_blessing` 内重读 `ProfileService.load_profile()`。

### 🟢 P3 — 经济/边角（记录在案）

#### M10 地图碎片 50 卢恩一刀切
第 1 层买不起（最迷路时最贵）、第 11 层九牛一毛。可按层/幕递增（如 `30 + 10×floor`），让它始终是个"要掂量"的决策。

#### M11 小圆盾直接改 `stance_now`，可打到负值且无日志
`buckler` 钩子 `combat.enemy.stance_now -= 4` 绕过 `deal_enemy_damage`，不触发崩解、可负、无提示。下一击才吃 ×1.35 并崩解。能用，但和主流程两套姿态语义。建议统一走 `deal_enemy_damage(0, 4)`。

#### M12 NG+ 新鲜感只覆盖 2 个有二阶段的敌人
`phase2_moves` 只有玛尔基特与接肢贵族有。NG+ 混招对另外 16 个敌人 = 纯数值成长，重开时"敌人变了"的惊喜很稀。这是内容产能问题，先记录：后续给精英（熔炉骑士、守墓斗士）也补二阶段池，NG+ 才有持续新鲜感。

## 三、三支柱评估（本轮）

### Ⅰ 趣味性 —— 8 / 10（上轮 7.5）
姿态崩解→处决/防反→防反延续→蓄力打断，这套循环已经是同类里少见的"有手感的魂系决策"；破绽有「破绽！」chip、低姿态有金框、意图有每敌胶囊，信息喂得够。**扣分项**：M2 让初始卡成长缺位（陪伴最久的卡最先失去成长感）、M3 让终局泄气、M4 让打断叙事翻车。

### Ⅱ 可玩性 —— 7.5 / 10（上轮 6.5）
拖拽+点击双通道、瞄准线、多敌意图、碎片探图、暂停/存档齐备，交互骨架干净。**扣分项**：M6 属性描述误导加点、M8 誓约累积未说明——都是"玩家按错误信息做决策"的可玩性伤害，成本低、收益高，应优先。

### Ⅲ 可重复游玩价值 —— 7.5 / 10（上轮 7）
NG+×7、誓约Ⅰ–Ⅴ、誓言挑战、记忆/回响外循环，结构完整。**扣分项**：M1 直接污染重开体验（串档白嫖/丢档惩罚），M12 让 NG+ 的新鲜感天花板偏低。把 M1 修掉是重玩价值的地基。

## 四、建议实施优先级（S13 之后）

| 优先级 | 项 | 工作量 | 一句话 |

## 五、实施回执（P0–P3 全部落地）

| 项 | 落地方式 | 验证 |
|---|---|---|
| **M1** | `RunState.weapon_levels: Dictionary` 为唯一事实来源；`reset_for_origin` 清零；`WeaponService.max_weapon_level` 改读 run；`RunRewardFlow` 不再改共享 Resource；`RunSaveService` 序列化往返 | `round3_fixes_test`：串档清零 + 存档往返 + 共享资源恒 0 级 |
| **M2** | 钩子卡伤害统一走 `_hook_damage`：`（基础 + 武器攻击加成）× 武器等级倍率 + 力量`。**刻意不吃属性补正**——0 级全额属性补正会把力量系钩子卡抬到 3 倍伤害（一贫如洗 vs 玛尔基特 1.9 回合击杀、胜率 79%→100%），抹平难度锚点并使 M3 失效；武器倍率才是评审要求的 MUST | `round3_fixes_test`：club 伤害随武器等级增长（lv0 7 → lv5 10+） |
| **M3** | 「蜘蛛般的近身压迫」rot 6 → attack_rot 10+腐败3（一阶段有稳定直伤）；二阶段触发线 50%→65% | MC：一贫如洗对接肢贵族胜率 88.7%→**56.0%**，低于玛尔基特 78.7%，倒挂纠正 |
