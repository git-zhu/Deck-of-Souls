# 第四轮设计评审：内容记忆点与学习反馈——创新玩法提案（艾尔登法环 × 魂系学习环）

> 命题：以世界前 1% 游戏开发者视角，基于**艾尔登法环的有趣剧情/内容**与**魂类游戏的学习反馈机制**，为 Deck of Souls 寻找可落地的创新玩法。
> 前提：一～三轮已修完结构性缺陷（M1–M12），48 测试全绿，难度锚点健康（一贫如洗 vs 玛尔基特 78.7% / 接肢贵族 56.0%）。本轮不修 bug，只谈"下一步往哪长"。

## 结论先行

当前游戏有**扎实的机制骨架**（姿态/崩解/防反决策、先手压制、NG+/誓约/记忆外循环），但缺两样让它"被记住"的东西：

1. **内容记忆点。** 玩家聊艾尔登法环时说得出名字：初见黄金树、壶哥亚历山大、燃烧大树、承接癫火、追忆换武器。这些不是过场动画，而是**系统化的仪式时刻**——可重复游玩的游戏里，剧情不靠播片，靠"每次都会发生、但每次选择不同的事件结构"。本作目前 21 个事件大多是数值交易，没有一个能说出名字的瞬间。
2. **学习反馈的最后一公里。** 魂类的本质教学循环是"死亡 → 信息 → 变强"：血迹告诉你别人怎么死的、尸体跑让你为失误付出代价、捷径解锁奖励探索、BOSS 无限重开练出肌肉记忆。本作已有死亡回响（**资产的**跨局回收），但死亡只留下卢恩，不留下**知识**与**机械补偿**。"死了 → 夺回响 → 再战"离"死了 → 懂了 → 真的变强了"还差一步。

据此提出 **I1–I9 九项创新**，分三簇：学习反馈（A）、内容记忆点（B）、禁忌抉择（C）。
**若只做三件事：I1（类型之魂）→ I5（性价比之王）→ I4（辨识度最高的法环系统）。**

## 一、现状诊断

| 维度 | 已有 | 缺口 |
|---|---|---|
| 死亡惩罚/回收 | 死亡回响（souls/2 夺回或换记忆） | 死亡无"死因记录"，玩家重开时得不到针对性信息 |
| 练习渠道 | 无 | 没有低风险重战（魂类的无限重开练肌肉记忆缺失） |
| Boss 奖励 | 卢恩 + 常规卡牌奖励 | 无专属感：打赢玛尔基特与打赢杂兵在奖励结构上无质的区别 |
| 路线决策 | 三选一层层走 | 无"朝圣/绕路"型主动决策（地图层只挑节点，不做赌注） |
| 仪式时刻 | 无 | 终局前无不可逆的献祭/抉择，结局单一 |
| NPC | 商人（纯功能）、事件文案 | 无跨层重复出现的角色，无人"等你回来" |
| Build 禁忌 | 誓约（开局自选减益） | 无**局内**不可逆的高风险高回报堕落路线 |

## 二、提案族 A：学习反馈（死亡即老师）

### I1 死亡回响 · 死因解析与对策记忆 —— P0 · 中 · ★★★★★

**原型**：黑魂血迹显示他人死状；魂系学习靠"死亡信息跨死亡存续"。
**设计**：
- 战斗失败时记录死因到 `profile.echo`（扩展现有结构）：杀手名、致死招式（最后一击的 intent text/kind）、过甲伤害、当时是否处于崩解/蓄力状态。`record_death` 已在 `Main._show_game_over` 调用，`CombatController` 持有全部所需状态。
- 死亡结算屏（`EndScreenView.build_game_over`）新增**死因解析**行："你死于 玛尔基特 的《恶兆审判》——18 点未格挡伤害。回响提示：他抬杖蓄力时，是你打破姿态的窗口。"
- 教学提示数据化：`EnemyData` 增 `lore_tip: String` 字段，每个 boss/精英写一条"背板攻略式"提示（魂式：知识写进世界，不写进教程）。
- **对策记忆（关键创新）**：下一局再遇到杀死过你的敌人（按 enemy name 匹配），获得一次性小额补偿——**该敌人前两次攻击各 −2 伤害**（"你记得它出手的前摇了"）。数值刻意做小：是象征性认可，不是死亡福利，防止"求死刷补偿"。
- 承接点：`ProfileService.record_death` 扩参；`CombatController.start_combat` 读 profile 注入 flag；`CombatHudView` 显示"对策记忆"芯片。
**为什么值得**：直接把魂类的"死亡教学"翻译成 roguelite 的跨局语言——每一次死亡都在机械意义上让你下一局更强一点，这是本作与所有 StS-like 的差异点。

### I2 血迹地图 —— P0（随 I1）· 小 · ★★★☆

**原型**：联机血迹/留言；单机化 = 与自己的历史对望。
**设计**：进入与上局死亡同层的楼层时（`floor_index` 匹配 echo.floor），地图顶部显示血迹行："此地有你的血迹——你曾死于 接肢贵族（第 11 层）。" 查看血迹：下一场战斗首回合 +1 抽牌（"警惕让你更敏锐"）。
**承接点**：`MapScreenView.build` 读 profile echo；一次性 flag 存 RunState。
**注意**：地图节点跨局不稳定（种子不同），只锚定层数，不锚定节点——这也更符合"血迹是地域记忆而非精确坐标"的魂味。

### I3 追忆决斗（Boss 修炼场）—— P2 · 中 · ★★★★

**原型**：魂类 BOSS 可无限重开练肌肉记忆；roguelike 天生没有练习模式。
**设计**：赐福新增选项"追忆决斗"：选择**本局已击败**的任意 boss，以同难度重战。决斗中死亡 = 决斗失败（回到赐福，不掉血不掉卢恩）；决斗胜利 = 获得记忆 5–10（按 boss 档级）。每个 boss 每局限一次。
**承接点**：`GraceService` 选项池 + `Main` 特殊战斗路由（combat kind="rematch"：defeat 不触发 `_show_game_over`，走新结算）。
**为什么值得**：把"练习"本身接进外循环经济——熟练度直接产出记忆货币，学习有了价格。
**风险**：白嫖防刷（限一次/boss/局）；UI 需要 boss 选择列表。

## 三、提案族 B：内容记忆点（法环的仪式时刻）

### I4 大卢恩朝圣 —— P1 · 中大 · ★★★★★

**原型**：法环大卢恩必须去神授塔激活——两段式奖励 + 朝圣路线决策，辨识度最高的系统之一。
**设计**：
- 击败幕末 BOSS 后获得该幕**大卢恩（未激活）**（run flag；RunHeaderView 展示）。
- 下一幕地图注入第四个固定选项"**神授塔**"（不参与权重抽样，仅当持有未激活大卢恩时出现）：进入 = 一场精英试炼（塔的守卫）；胜利 = **二选一激活**：
  - **玛尔基特大卢恩**：「恶兆之力」全属性 +2 ／「恶兆之血」战斗开始 +1 力量
  - **熔炉骑士大卢恩**：「百相之韧」姿态削减 +20% ／「百相之甲」每回合 +2 护甲
  - **接肢贵族大卢恩**：「接肢之力」武器攻击加成翻倍 ／「龙首」最大生命 +15
- 激活 = 获得对应规则护符（**复用 relic 管道**：新增 6 个 hook，RelicService 已验证可扩展），朝圣失败/跳过 = 大卢恩保持未激活，下一层还有机会（每幕只注入一次，错过不补——朝圣是有代价的）。
**为什么值得**：地图层第一次出现"主动赌注型"决策（多打一场精英换 build 定义权），且两段式奖励天然制造"下次再来激活"的重开动力。
**风险**：6 个新 relic hook + 新节点 kind 的 UI（MapScreenView/RunFlowController 路由）——是本清单工作量最大项。

### I5 追忆二选一 —— P0 · 小中 · ★★★★★

**原型**：追忆 = BOSS 之魂换两件独占装备**二选一**；漫步灵庙可复制。
**设计**：BOSS 战奖励流追加"追忆"环节：两件该 BOSS 的**独占卡**二选一：
- **玛尔基特的追忆**：《恶兆审判》重击 18、施加易伤 1 ／《恶兆锁链》4×4 连击
- **熔炉骑士的追忆**：《百相之翼》重击 16、姿态 8 ／《百相之角》获得 12 护甲、下次攻击 +8
- **接肢贵族的追忆**：《接肢巨龙》全体 12、腐败 2（消耗）／《王族腐败》单体 8、腐败 5
- 追忆卡不入任何商店/奖励池——**只能从 BOSS 身上取得**（独占感）。
- 漫步灵庙机制 → **NG+ 特典：NG+ 及以上，追忆可以两件都拿**。一条规则同时强化 NG+ 价值与收集驱动力。
**承接点**：6 张新卡（data/cards）；`RunRewardFlow` boss kind 分支加追忆二选一（复用现有卡牌选择 UI）。
**为什么值得**：全清单性价比之王——6 张卡让三场 BOSS 战在奖励结构上与普通战彻底拉开档次，"我拿的是审判还是锁链"天然成为玩家间谈资与重开理由。

### I6 少女的引火 —— P0 · 小 · ★★★★

**原型**：梅琳娜燃烧黄金树——不可逆献祭标记终幕开启，全游戏最重的仪式时刻。
**设计**：进入第 11 层（终局前夜）时**强制注入**事件「巨人火焰的锻炉」，三选：
- **献出圣杯瓶**：本局 max_flasks −1（不可逆）→ 获得「灭裂之火」：终局 BOSS 最大生命 −15%，你的伤害 +10%。
- **献出武器**：移除一把武器及其全部强化等级 → 获得《献剑》传说卡（高伤、每战限用）。
- **拒绝献祭**：以完整之姿直面终局（无加减——拒绝本身是一个有尊严的选项，魂式）。
- 文案用红色警示"此决定不可撤销"；EndScreen 结局文本按献祭类型分化一句。
**承接点**：`RunFlowController` 在 floor_index==10 推进时注入；`EventService` 增 2 个 effect（sacrifice_flask/sacrifice_weapon——后者复用 PICK_CARD 选择管道）。
**为什么值得**：小成本制造戏剧结构：当前第 10–12 层是平铺的，这个事件把它变成"前夜 → 献祭 → 终局"三幕。

### I7 壶哥任务线（ recurring NPC ）—— P2 · 中 · ★★★★

**原型**：铁拳亚历山大——三度相遇、一路向东、终局相赠，玩家最惦记的 NPC。
**设计**：三段链式事件（复用 `follow_event_id` + 新增 run event_flags 判定）：
1. **第 2–3 层「陷在坑里的战壶」**：救他（回满圣杯瓶）或无视。
2. **第 6–7 层「战壶的试炼」**：仅当 ①救过他时出现——切磋一场（对"战壶亚历山大"精英模板），胜利赠护符「壶之碎片」（战斗开始 +3 护甲）。
3. **第 10–11 层「战壶的告别」**：赠传说卡《巨壶之拳》，并在结局文本留一句"某个壶，走到了他想去的地方"。
**承接点**：3 个事件 tres + 1 个精英模板 + 1 护符 + 1 卡；`EventService.is_choice_eligible` 需要支持"读 run flag"的条件扩展。
**为什么值得**："有人在前面等我"是 roguelike 里最被低估的重开理由；三段链也示范了事件系统从"数值交易"升级为"人物弧光"的路径。

## 四、提案族 C：禁忌抉择（风险原型）

### I8 癫火圣约 —— P1 · 中 · ★★★★

**原型**：三指癫火——不可逆禁忌、隐藏结局、"力量与代价"的终极表达。
**设计**：低概率事件「三指教堂」：承接癫火（不可逆）：
- **得**：造成伤害 +25%、每回合能量 +1；4 张癫火专属卡入奖励池（强力但自伤，如《癫狂烈焰》全体 14、自损 6）。
- **失**：受到伤害 +25%；赐福治疗减半。
- **终局**：结局变为「癫火之王」（独立结局文本 + profile 记录成就标记）；誓言挑战新增"以癫火通关"。
**承接点**：run flag `frenzied_flame`；乘数走誓约同款管道（`apply_vow_start` 是先例，`CombatController` 的伤害进出各挂一处乘数）；4 卡 + 1 事件 + 结局分支。
**为什么值得**：给高端玩家一条"堕落 build"原型——誓约是开局选的减益，癫火是**局内捡的力量**，两者一冷一热构成完整的风险光谱。

### I9 杀死商人 —— P1 · 小 · ★★★☆

**原型**：法环可以杀商人，铃珠继承库存——后果系统化的黑暗选择。
**设计**：本局**第一个**商人节点额外提供选项「下手」：免费获得其全部库存 + 护符「卡勒的铃珠」（之后……没有之后了）；代价：本局不再出现任何商人节点（`MapGenerator` 按 flag 剔除 merchant）。
- 决策张力：3 件免费货 vs 后续 2–3 次购物机会；富局/冲速局划算，build 未定型局血亏——**情境依赖的黑暗选择**，正是魂味。
**承接点**：MerchantService 加 flag；RunState 记 `merchant_killed`；1 个新护符（纯纪念/叙事型，无需 hook 逻辑）。
**风险**：无——系统面极小，纯加分项。

## 五、不做的事（克制清单）

1. **不做实时弹反 QTE。** 回合制的防反已经翻译成"崩解后防反"的决策时刻，加实时判定会破坏纯度。
2. **不做灵体召唤（持久盟友单位）。** 诱人但引擎级改动：需要新的战斗实体、敌方目标选择 AI、盟友行动结算——风险与当前体量不匹配。观察项：若 I4/I5 落地后仍需新战斗维度，再评估"极简灵体"（只有 HP 与嘲讽的 token）。
3. **不做隐藏第 13 层/圣树密符。** 好点子但依赖 I4/I5 先建立"收集型内容"的玩家心智，暂缓至下一轮。
4. **不做真联机。** 规模不符；I2 血迹已把联机体验单机化。
5. **对策记忆（I1）数值不得做大。** 它是"认可你学到了"，不是"补偿你死了"；一旦大到值得故意去死，整个学习环就崩了。

## 六、优先级与实施顺序

| 优先级 | 项 | 工作量 | 一句话 |
|---|---|---|---|
| P0 | **I1 死亡回响·死因解析+对策记忆**（含 I2 血迹） | 中+小 | 类型之魂：死亡第一次留下知识 |
| P0 | **I5 追忆二选一** | 小中 | 6 张卡，BOSS 从此有重量 |
| P0 | **I6 少女的引火** | 小 | 终局前的仪式时刻 |
| P1 | I4 大卢恩朝圣 | 中大 | 辨识度最高的法环系统 |
| P1 | I8 癫火圣约 | 中 | 堕落 build 与隐藏结局 |
| P1 | I9 杀死商人 | 小 | 小而黑的后果系统 |
| P2 | I7 壶哥任务线 | 中 | 有人在前面等你 |
| P2 | I3 追忆决斗 | 中 | 练习产出记忆货币 |

**若只做三件事**：I1 → I5 → I4。分别回答"死亡教会你什么""胜利奖赏你什么""你愿意为谁绕路"——学习、奖赏、抉择，正好覆盖本轮命题的两条矿脉。
