## 二、UI 设计现状

### 2.1 主题与视觉

- 统一配色 `GameTheme`：暗色底 `#16130f`、面板 `#242018`、金色高亮 `#e0c06c`，艾尔登法环"褪色者"气质。
- 全局字号：Label 18 / Button 17 / RichTextLabel 16；卡片 14。
- 意图着色（攻击红 / 格挡金 / 增益紫 / 减益绿）；地图节点类型徽章（战斗/精英/Boss/赐福/商人/事件）。

### 2.2 屏幕与视图

| 屏幕 | 视图 | 布局要点 |
|------|------|---------|
| 标题 | `TitleScreenView` | 居中大标题 + 副标题 + 三按钮（新游戏/继续/退出），继续按钮无存档时禁用 |
| 出身 | `OriginScreenView` | 3 列网格 × 6 出身卡（名字/等级/属性/装备/备注/开始按钮） |
| 地图 | `MapScreenView` | 幕标题 + 副标题 + 横向 3 选项卡（类型徽章/名称/正文/踏入按钮） |
| 战斗 | `CombatHudView` | 左玩家面板 / 中意图+日志 / 右敌人面板；底部手牌横向滚动 + 圣杯瓶/结束回合 |
| 奖励 | `RewardLayerViews` | 商人/赐福/事件/战后选牌/选牌移除等统一卡片布局 |
| 暂停 | `RunPauseMenuView` | 全屏半透明遮罩 + 居中三按钮 |
| 结算 | `EndScreenView` | 居中死亡/胜利文案 + 按钮 |
| 牌组 | `DeckPopupView` | AcceptDialog + 牌组摘要 + 可滚动卡牌列表 |
| 顶栏 | `RunHeaderView` | 生命/瓶/卢恩/护符/记忆石/牌组/幕层数 + 查看牌组 + ☰ 菜单 |

### 2.3 UI 验证现状

- `ui_layout_test`：校验主题色/意图色/地图卡片徽章。
- `smoke_test`：1280×720 视口下校验敌人面板不越界、手牌行高度。
- `origin_screen_test`：6 出身按钮 + 点击回调。
- **缺口**：尚无全屏幕 UI 截图验证；无音效；顶部/地图/结算屏的视觉冒烟偏少。

## 三、开发计划（含优先级）

> 依据 CLAUDE.md "Recommended Next" 与本日评估。第四幕（16 层）**暂缓**，不在近期计划。

> **执行状态（2026-05-23）：P0 / P1 / P2 均已落实并推送（commit 942d032 / 5e11087 / 1dd623d）。**

### P0 — 默认音效包（audio/*.ogg + 路径测试） ✅ 已完成

**目标：** 让 `GameAudio` 三个钩子（`ui_click` / `victory` / `defeat`）真正发声。
**内容：**
1. 生成 3 个短 OGG（合成音即可，CC0 自产）：`ui_click.ogg`（短促点击）、`victory.ogg`（上扬和弦）、`defeat.ogg`（低沉下行）。
2. 新增 `tools/audio_path_test.gd`：断言三个 `res://audio/*.ogg` 存在且可 `load` 为 `AudioStream`，且 `GameAudio.play` 在资源存在/缺失两种情况下均不报错。
3. 更新 `audio/README.md` 与 `CLAUDE.md` 测试清单。

### P1 — UI 验证与完善（1280×720 全屏冒烟） ✅ 已完成

**目标：** 把所有核心屏幕纳入自动化 UI 校验。
**内容：**
1. 新增 `tools/ui_screen_test.gd`：实例化 Main，依次进入 标题→出身→地图→战斗→商人→赐福→事件→死亡/胜利，断言每个屏幕的关键控件存在、面板不越出 1280×720。
2. 修正发现的布局问题（若有）。
3. 可选：补 1–2 处高价值 UI 打磨（如地图卡片 hover 高亮、牌组弹窗滚动条样式）。

### P2 — Monte Carlo 平衡工具（可选） ✅ 已完成

**发现：** 预言家（prophet）裸卡组对 Boss 胜率仅 ~20%（其余出身 ≥57%）；普通/精英战对裸卡组全 100% 偏易。详见 `.gstack/qa-reports/monte-carlo-balance-analysis-2026-05-23.md`。

**目标：** 提供快速自动战斗模拟，评估卡组/敌人数值健康度。

---

### P3 — 预言家（prophet）Boss 平衡调整 ✅ 已完成（依据 P2 报告）

**修复：** `data/origins/prophet.tres` — 初始牌组 `heal` → `black_flame`（12 伤害 + 3 易伤，信仰/火焰主题）。

**效果（Monte Carlo 200 场复测）：** 玛尔基特胜率 21.3% → **76.0%**；接肢贵族 18.7% → **66.5%**。

**回归：** 全量 27 项 headless 测试通过。
**内容：**
1. 新增 `tools/monte_carlo_balance.gd`（SceneTree 脚本）：随机生成 N 局模拟——按出身初始牌组 + 简单贪心出牌策略，对每幕敌人池模拟胜负率/平均剩余 HP/回合数。
2. 输出统计摘要；不强制门禁，仅作平衡决策参考。
