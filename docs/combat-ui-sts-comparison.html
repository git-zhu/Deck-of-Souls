二、布局结构对比

DoS 当前：5 层纵向分割

层级内容高度问题
① Header HP / 瓶位 / 卢恩 / 进度 / 牌组数（RunHeaderView） ~46px HP 重复 与玩家面板重复显示生命
② TopBar 回合数胶囊 + 能量球居中（CombatHudView top_bar） ~60px 资源分散 能量球与 HP 物理分离
③ Stage 敌人（上部居中）+ 投放间隙 + 玩家（底部居中） 弹性 ~280px 上下堆叠 玩家与敌人是上下关系，非左右对抗
④ Hand 圣杯瓶按钮 + 抽牌徽标 + 手牌卡 × 5 + 弃牌/消耗徽标 ~160px 信息过载 6 种元素混在同一行
⑤ CTA 结束回合按钮 220×64 独占一行 ~80px 空间浪费 独占 ~80px 垂直空间

StS 参考：3 层 + 角落徽标

层级内容位置特点
① 资源区 玩家面板 (HP + Block + 状态图标) + 能量球 + 回合数 左上 + 右上 单行扫描 所有核心数据在一条线上
② 舞台 敌人立绘 + 意图气泡（头顶外部）+ HP 条 中上部 大量留白 给飘字 / 粒子 / 牌飞行动画
③ 手牌 5 张手牌扇形居中 底部居中 干净 无多余按钮 / 徽标
角落 抽牌堆（左下）+ 弃牌堆（右下）+ 能量球（右侧，双击结束回合） 底角 + 右侧 三角框架 稳定的视觉三角
